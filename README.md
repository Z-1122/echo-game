# 回声 · ECHO

一个把「**过去的自己**」变成护盾与收集器的创意小游戏。单文件 HTML，零依赖，双击即玩。

## 创新点

大多数弹幕游戏里，"躲"就是全部。这个游戏把你的**移动轨迹本身变成一种可回收资源**：

按下空格，游戏会把你**过去 1.4 秒的移动轨迹**复制成一个"回声"。这个回声沿着那条轨迹来回巡逻，然后：

- **替你吸收子弹** —— 回声不会受伤，但只存活 9.5 秒
- **替你收集光点** —— 光点既是分数，也是能量来源

于是你的走位不再只是躲避，而是在**布置未来**：

- 绕一圈，把回声铺成一道会巡逻的防线
- 或者走一条穿过光点群的路线，让它替你自动刷分

「你的过去既是护盾，也是你的收集器。」

## 操作

| 按键 | 作用 |
| --- | --- |
| `WASD` / 方向键 | 移动 |
| `空格` | 召唤回声（消耗 28 能量，最多同时 3 个） |
| `Shift` | 冲刺，短暂无敌，冷却 1 秒 |
| `P` | 暂停 |
| `M` | 静音 |

## 玩法规则

- 竞技场四角的红色**哨兵**会向你射击；波次越高，射速越快，第 6 波起变成三连发
- 每 **16 秒**进入下一波，场上哨兵数量随之增加（最多 7 个）
- 每 **3 波**回复 1 点生命，生命上限 5
- 初始 3 点生命，生命归零即结束
- 最佳分数保存在浏览器 `localStorage` 中

## 运行

直接双击 `echo.html`，或用浏览器打开即可。**不需要联网、不需要安装任何东西、不需要服务器。**

也可以用任意静态服务器托管：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/echo.html
```

## 技术实现

- **纯 Canvas 2D** 渲染，无任何第三方库
- **WebAudio 实时合成音效**，不加载任何音频文件，整个游戏仅一个 HTML 文件（约 36 KB）
- 视觉：霓虹矢量风，含辉光、粒子、冲击波、屏幕震动、冲刺残影
- 轨迹录制使用 60Hz 环形缓冲（`REC_MAX = 84`，即 1.4 秒），回声在轨迹上做 ping-pong 巡逻
- 画布逻辑分辨率 960×600，按设备像素比自适应缩放
